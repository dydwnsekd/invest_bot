# 지식 문서 작성 양식

새 파일을 만들기 전에 같은 주제를 담당하는 문서가 [등록부](catalog.md)에 있는지 확인한다. 아래 양식을 복사해 필요한 항목만 채우고, 등록부에 ID·경로·종류·상태·관리 역할·담당 주제를 추가한다.

```markdown
# 문서 제목

## 목적과 범위
이 문서가 답하는 질문과 다루지 않는 범위.

## 현재 사실 또는 제안
현재 동작과 앞으로의 목표를 분리한다. 불명확하면 미확인이라고 표시한다.

## 근거
- 관련 코드·계약·마이그레이션 링크
- 검증 명령, 실행 날짜, 대상 버전, 결과와 제외 범위

## 관계
관련 개념 ID와 문서 링크. 대체하는 문서가 있다면 그 문서도 연결한다.

## 남은 차이
설계와 구현의 차이, 미검증 항목, 후속 작업.
```

결정 기록에는 문제·선택·이유·대안·제약을 추가한다. 실행 보고에는 수행한 작업과 검증 증거를 적는다. 파일 경로는 저장소 안에서 이동 가능한 상대 링크로 작성하고, 로컬 사용자 홈 경로·자격 정보·운영 데이터는 넣지 않는다.
