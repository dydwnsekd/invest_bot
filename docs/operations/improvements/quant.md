## G03 — 중복 거래일 계약

- **우선순위:** P1 · **상태:** 대기 · **선행:** 없음.
- **근거:** [runner:27·224](../../../src/invest_bot/backtest/runner.py)는 모든 행을 체결에 사용하지만 평가곡선에는 같은 날짜의 마지막 행만 남긴다. 중복 입력이 [readiness](../../../src/invest_bot/backtest/readiness.py)를 통과하고 거래 수익률0%·요약100%인 fixture를 재현했다. 운영 백테스트의 실제 발생 여부는 검증하지 않았다.
- **작업:** readiness·runner·평가곡선의 날짜 유일성 계약을 통일한다. 중복을 명확히 차단하거나 동일한 정규화 규칙을 적용한다.
- **완료 조건:** 재현 입력이 정한 정책에 맞게 처리되고 거래 로그·곡선·요약의 성과가 같은 입력으로 설명된다. 정상 입력의 체결·보유 중 MDD·첫 손실·무거래 동작을 보존한다. 거래가 없는 상태나 미청산 보유분은 거래 수익률만으로 최종자산과 같다고 강제하지 않는다.
- **검증 경로:** [adapter·runner 회귀](../../../tests/test_backtest_adapters_runner.py)와 readiness 검증. 중복·정상·미청산 사례를 구분한다.

<a id="g04"></a>
## G04 — 저장 신호의 날짜·가격 정합성

- **우선순위:** P1 · **상태:** 대기 · **선행:** G03.
- **근거:** [adapter:114](../../../src/invest_bot/backtest/adapters.py)는 저장 골든크로스 신호의 컬럼을 확인하지만 현재 지표와 날짜·가격을 대조하지 않는다. 지표가 4월 3일까지인 fixture에서 4월 4일 저장 신호 가격이 사용됐다.
- **작업:** 현재 지표와 저장 신호의 기간·거래일·종가 정합성을 확인하고 불일치 시 재계산 또는 명시적 차단 정책을 정한다.
- **완료 조건:** 오래된 신호·범위 초과·같은 날짜 가격 불일치를 각각 검증한다. 정상 저장 신호 결과를 보존하고 현재 입력 범위 밖 가격을 성과 계산에 사용하지 않는다.
- **검증 경로:** [adapter·runner 테스트](../../../tests/test_backtest_adapters_runner.py), [백테스트 생성 테스트](../../../tests/test_backtest_generator.py). G08a 수집 범위 개선에 의존하지 않는다.

<a id="g08c"></a>
## G08c — 조합 실험 설정 저장·재로드

- **우선순위:** P2 · **상태:** 대기 · **선행:** G03·G04 · **연결:** [QA03](qa.md#qa03), 대시보드 생성 연결부.
- **근거:** [조합 metadata:713](../../../src/invest_bot/dashboard/streamlit_backtest.py)에는 전략 ID·가중치·방식만 저장된다. RSI40/60 실행 fixture의 조합 `strategy_parameters_json`이 `{}`였다. [조합](../../../tests/test_backtest_combination.py)과 [실험 설정](../../../tests/test_backtest_parameters.py)은 저장 후 재로드까지 연결하지 않는다.
- **작업:** 구성 전략별 유효 설정·신호 출처·입력 provenance를 조합 출력과 artifact에 보존한다. 퀀트가 계약을 담당하고 대시보드 파일의 생성 연결부는 메인이 소유권을 조정해 순서대로 수정한다.
- **완료 조건:** RSI 설정만 바꾸면 metadata가 구분된다. RSI40/60을 포함한 조합 실행→임시 artifact 저장→새 service 재로드에서 구성 설정·방식·가중치·입력 출처·거래·최종자산·MDD가 일치한다. 중복 날짜는 G03의 정책을 적용한다. 기존 저장 이력의 호환 범위도 명시한다.
- **검증 경로:** [백테스트 저장](../../../tests/test_backtest_persistence.py), [대시보드 백테스트](../../../tests/test_streamlit_backtest.py), 조합·파라미터 회귀. G08a에 의존하지 않는다.
