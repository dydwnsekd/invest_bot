<a id="g05a"></a>
## G05a — 차트 summary 수급 연결

- **우선순위:** P1 · **상태:** 대기 · **선행:** [G01a](data.md#g01a) · **검증:** [QA02](qa.md#qa02).
- **근거:** [chart loader:72·123](../../../src/invest_bot/dashboard/streamlit_state.py)는 날짜 없는 detail의 병합을 포기한다. 데이터 세션이 유효 summary를 함께 넣은 fixture에서 OHLCV만 남는 경로를 재현했다. [리포트 생성기:66](../../../src/invest_bot/jobs/generate_market_report.py)는 실제 summary 날짜·수급을 사용한다. 기존 [차트 fixture](../../../tests/test_dashboard_snapshot_frame_loader.py)는 detail에 날짜가 있는 형태다.
- **작업:** 실제 summary 관측일의 수급을 기존 snapshot으로 연결한다. summary 사용 자체가 오류라는 이전 추론은 철회됐으며 데이터 계약을 변경하지 않는다.
- **완료 조건:** summary만 유효한 fixture에서 날짜별 수급값을 표시한다. 원본이 없거나 날짜가 맞지 않으면 값을 만들지 않고 사유를 표시한다. snapshot 생성 후 추가 SELECT0회를 유지한다.

<a id="g05b"></a>
## G05b — 원본·판단 기준일과 다음 행동

- **우선순위:** P1 · **상태:** 대기 · **선행:** G05a. 생성된 판단의 정확성 완료 표시는 [G03·G04](quant.md) 검증 이후 · **검증:** QA02.
- **근거:** [관심종목:324](../../../src/invest_bot/dashboard/streamlit_watchlist.py)는 분석 갱신 필요를 구분하지만 [홈:156](../../../src/invest_bot/dashboard/streamlit_overview.py)은 오래된 리포트에 수집까지 권고하고 [리포트:553](../../../src/invest_bot/dashboard/streamlit_reports.py)는 일반 기준일 안내를 사용한다.
- **작업:** 기존 상태 계산을 재사용해 홈·리포트·관심종목의 원본 날짜·판단 날짜·필요 단계를 통일한다. 판단 날짜를 최신 원본 날짜로 덮어쓰지 않는다.
- **완료 조건:** 원본10/02·분석 이전 날짜, 원본 누락, 날짜 불일치를 각각 구분한다. 원본 최신·분석 지연이면 분석 갱신을 안내한다. 검색·선택·탭 이동은 선택 상태만 복원하며 수집·분석·생성·전송 호출0회를 유지한다.

<a id="g06a"></a>
## G06a — 생성·전송 범위 안내

- **우선순위:** P1 · **상태:** 대기 · **선행:** 없음 · **검증:** QA02의 호출 경계.
- **근거:** [actions:214](../../../src/invest_bot/dashboard/streamlit_actions.py)의 리포트·파이프라인 실행은 Discord 전송을 요청하지만 클릭 전 안내가 없다. 설정 여부와 실제 전달 성공은 별개다.
- **작업:** 버튼 주변에 대상 종목·실행 단계·Discord 전송 설정 여부를 표시한다. 기존 실행·전송 정책은 보존한다.
- **완료 조건:** 클릭 전에 안내를 확인할 수 있다. 조회·선택만으로 실행0회, 클릭 mock에서는 기존 호출횟수와 부분 실패 표시를 보존한다. 실제 전송 성공을 설정만 보고 보장하지 않는다. 안내 수정 검증에는 실제 Discord 호출이 필요하지 않다.

<a id="g06b"></a>
## G06b — 상태 텍스트 대비

- **우선순위:** P1 · **상태:** 대기 · **선행:** 없음 · **검증:** QA02의 실제 브라우저.
- **근거:** 10월 3일 화면에서 중립 신호가 어두웠고 [formatter:103](../../../src/invest_bot/dashboard/streamlit_formatters.py)의 `#111827`을 [기존 테스트](../../../tests/test_streamlit_dashboard.py)도 고정한다. 색상값을 그대로 보존하는 테스트만으로 가독성을 확인할 수 없다.
- **작업:** [styles](../../../src/invest_bot/dashboard/streamlit_styles.py)와 formatter의 상태 대비·보조 글자 크기를 기존 네이비·Pretendard·컴포넌트 체계 안에서 조정한다.
- **완료 조건:** 렌더링된 배경 기준 일반 텍스트 대비4.5:1 이상, 보조 라벨0.8rem 이상. 중립·매수·매도 상태, 키보드 포커스·아이콘을 실제 브라우저에서 확인하고 관련 회귀를 갱신한다.

<a id="g06c"></a>
## G06c — 헤더·카드·필터 배치

- **우선순위:** P2 · **상태:** 대기 · **선행:** G05b.
- **근거:** 10월 5일 화면 재확인에서 큰 소개와 반복 설명이 종목 선택·판단 접근을 밀었다. [layout:153](../../../src/invest_bot/dashboard/streamlit_layout.py), [리포트 UI](../../../src/invest_bot/dashboard/streamlit_reports.py)의 배치를 정돈할 수 있다. 그림자·테두리 축소는 사용성 결함과 구분되는 시각 제안이다.
- **작업:** 헤더·반복 설명을 압축하고 카드·검색·필터·정렬을 정돈한다. 기준일·상태·경고는 선택 대상과 함께 확인할 수 있게 한다.
- **완료 조건:** 같은 fixture의 1920×958·390×844 전후 화면에서 선택·판단·경고를 찾을 수 있고 잘림·겹침이 없다. 선택 복원·상세 이동·키보드 포커스·아이콘과 snapshot 이후 추가 SELECT0회를 보존한다. 시각 취향 변경은 전후 화면으로 검토한다.

<a id="g08b"></a>
## G08b — 백테스트 실제 입력 범위

- **우선순위:** P2 · **상태:** 대기 · **선행:** G03·G04.
- **근거:** [백테스트 UI:507](../../../src/invest_bot/dashboard/streamlit_backtest.py)에서 사용자가 요청한 수집 기간과 실제 입력 기간을 구분할 필요가 있다. 365일 요청에100행만 확보되는 후보는 [G08a](data.md#g08a)에 별도로 등록했다. 이 항목의 잘못된 표시를 독립 fixture로 재현한 결과는 아직 없다.
- **작업:** 실제 실행에 사용한 시작일·종료일·행수와 요청 범위를 함께 확인할 수 있게 한다.
- **완료 조건:** 실행 전 준비 상태와 실행 결과가 같은 입력 범위를 표시하고 단일·조합에서 선택 범위를 실제 사용 범위로 오인하지 않는다. 데이터 수집을 자동 실행하지 않는다. G08a를 기다리지 않고 구현할 수 있다.
- **검증 경로:** [대시보드 백테스트 테스트](../../../tests/test_streamlit_backtest.py), 실제 브라우저 표시 확인.

<a id="g08d"></a>
## G08d — 모바일 차트 범례

- **우선순위:** P2 · **상태:** 대기 · **선행:** G06c.
- **근거:** 기존390px 디자인 검토에서 차트 제목·범례 배치가 개선 후보였다. [charts:735](../../../src/invest_bot/dashboard/streamlit_charts.py)를 실제 모바일 화면과 대조한다. 코드만으로 현재 모든 차트의 겹침을 확정하지 않는다.
- **작업:** 좁은 화면의 제목·범례·수급 panel 배치를 정돈한다.
- **완료 조건:** 390×844에서 제목·범례·축이 겹치지 않고 읽을 수 있다. 데스크톱의 데이터·차트 spec·조작을 보존하며 전후 캡처로 검증한다.
