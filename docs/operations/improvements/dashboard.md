- **착수 정책 (2026-10-13):** 기존 유효 날짜·수급 상세 입력을 보존하며, 상세에서 관측일별 수급을 얻을 수 없으면 실제 날짜와 값이 있는 summary를 기존 snapshot에서 연결한다. 날짜 없는 상세 값을 가격 날짜에 복제하거나 날짜만 있는 summary로 다중 상세의 날짜를 추정하지 않는다. 누락·무효 날짜/값·차트 기간 불일치는 기존 상태 컴포넌트로 안내한다. 데이터 저장 계약·조회/생성 경계·다른 개선 항목은 변경하지 않는다.
- **반영 결과:** detail 전체 source를 우선하고 무효일 때 summary로 대체한다. source 사이의 누락 날짜·투자자 값은 섞지 않으며 숫자형 관측일·0·null을 구분한다. 가격 시각·시간대는 보존하고 실제 관측일로 연결하되, 같은 날 가격 행이 여러 개면 일별 수급을 복제하지 않는다. 가격 프레임의 잔여 수급 alias도 제거한다. 주·월봉의 모두 미관측인 수급은 null이다. QA02에서 고립된 실제 관측값도 보이도록 전문 수급 trace에 marker를 추가하고 null gap 연결은 명시적으로 금지했다.
- **검증:** 격리본·원본 관련199 passed, 원본 기본832 passed / 2 deselected. 실제 가상 데이터 앱의 리포트·관심종목·데이터 보기, 누락·불일치, 1920×958·390×844를 확인했다. chart loader 추가 SELECT0회·검색/선택/탭 왕복 실행·전송0회다. 전체 리포트 rerun은 기존과 같은 SELECT3(snapshot2 + 즐겨찾기1)이며 전체 snapshot 이후0회라는 주장은 하지 않는다. [검증 기록](../../tasks/04_dashboard.md#차트-summary-수급-연결-2026-10-13).
